# args: --demo-disk
# env:
#
# What a letter will carry: a file the browser is holding becomes part of a
# draft, and the sheet says so.
#
# This is the one place two apps meet. Mail asks the registry for the files
# app when it builds a compose's bar, and offers *attach* only while that app
# is in the build and holding something — the hold's other destination, the
# way a files panel wears `copy here`. Nothing in the shell knows either
# noun.
#
# Run with `--demo-disk`: the browser half walks the demo tree rather than
# whatever this machine's ~ holds, so the file can be addressed by name.
#
# Assertions are the clicks: *attach* resolving is the bar having grown it,
# and the file's name resolving is the CARRIES line naming it. A run can
# assert what is drawn and not what is gone, so the undo is checked by the
# redo that puts the line back.

wait 900

# -- the letter ------------------------------------------------------------------

# A conversation, and the reply its reader's bar opens: the sheet lands
# joined to the right, with the recipient already in it.
click "Q3 infra"
wait 900
click "reply"
wait 900
shot t1-compose

# -- the file --------------------------------------------------------------------

# A files panel in a column of its own — cmd+enter from the launcher is
# always un-joined — and a walk to the file. `go to` completes one segment
# at a time, and a click on the row previews the card that wears the object
# verbs.
key cmd 2
wait 400
type "files"
wait 500
key cmd+enter
wait 900
click "go to"
wait 500
type "Down"
wait 600
key tab
wait 400
key enter
wait 900
click "report-q3.pdf"
wait 900
shot t2-picked
click "copy"
wait 700

# The browser is walked away before the letter is asked to carry anything,
# so the only thing on screen wearing that name afterwards is the letter's
# own line. The card, joined under the panel that was replaced, goes with it.
click "go to"
wait 500
type "~/Documents/"
wait 600
key enter
wait 900

# -- attach ----------------------------------------------------------------------

# The sheet wears `attach` now: it asked the registry for the files app and
# found it holding one file. Clicking it is one undoable action.
click "attach"
wait 900
shot t3-carrying

# The CARRIES line names the file, which is what this resolves against.
click "report-q3.pdf"
wait 500

# cmd+z takes it straight back off the letter — and cmd+shift+z puts it
# back, which is how a run asserts a line that went away: by the one that
# brings it again.
key cmd+z
wait 900
shot t4-undone
key cmd+shift+z
wait 900
click "report-q3.pdf"
wait 500
shot t5-carrying-again
quit
