# Terminal symbol fonts

These unmodified fonts extend Geist Mono in the terminal's normal, bold, and
italic styles. Noto Sans Symbols 2 supplies Unicode dingbats and status marks;
Symbols Nerd Font Mono supplies Powerline and private-use prompt icons.

- `NotoSansSymbols2-Regular.ttf` comes from [Google Fonts commit
  8b0a1d0](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosanssymbols2).
  License: `NotoSansSymbols2-OFL.txt`.
  SHA-256: `7d5fb73b7ca67a6798101741f5d280a3d016a56a197afcd4199dbb57b4b82a21`.
- `SymbolsNerdFontMono-Regular.ttf` comes from [Nerd Fonts
  v3.5.1](https://github.com/ryanoasis/nerd-fonts/tree/v3.5.1/patched-fonts/NerdFontsSymbolsOnly).
  License and icon-set attribution: `NerdFontsSymbols-LICENSE.txt` and
  `NerdFontsSymbols-README.md`.
  SHA-256: `fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749`.
