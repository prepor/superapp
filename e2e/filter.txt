# CR-006 — the rich table's filter: tags, the autocomplete, values on
# demand, and a list that pages as it scrolls.
#
# Assertions are the clicks: a row that does not resolve fails the run, so
# "the filter kept Vera's mail" is checked by the run rather than by a
# human reading a screenshot.
wait 900
click "inbox"
wait 300

# `/` focuses the filter; `@` opens the tag list under it.
key /
wait 300
type "@"
wait 400
shot f1-tags

# The arrows walk the offer, enter takes it: `@html ` lands in the field
# (a boolean tag ends the token), and the box closes.
key down
wait 200

wait 500

wait 300
click "[stelaxis]"
wait 600
