# The four mailboxes: one panel over the inbox, the archive, sent and spam.
#
# Assertions are the clicks, and each list is asked for a row only its own
# folder holds — so a label that resolves is proof the right folder answered.
# Exactly one mail list is open at a time (the boot inbox is closed first,
# and each mailbox is closed before the next opens): two of them on screen
# would make "click the CI conversation" mean either, and the run would
# stop asserting anything.

# run is about the other three.
