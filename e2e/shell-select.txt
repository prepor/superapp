# args:
# env:
#
# Read-only content is selectable: an address, a payload, a sentence out of a
# log are things people copy, so the runs that carry them are real text runs
# and not labels.
#
# What each half checks:
#
#   `selectall` is the assertion. Keyboard selection needs no pointer capture,
#   so the wash it leaves is the proof that the run selects and renders — and
#   the label resolving at all is the proof that the run was drawn where the
#   panel says it was.
#
#   `drag` only checks that the run is found and that dragging across it
#   breaks nothing. A synthesized drag cannot reproduce the platform's pointer
#   capture, so it does not prove a selection appears.

wait 900

# The inbox that boots is closed: the two panels below are the workspace.
key cmd+w
wait 700

key cmd 2
wait 500
type "help"
wait 500
key enter
wait 900

# Something for the log to hold: the manual's demo copies a line, which is a
# real effect and so a real row.
click "try it"
wait 700

key cmd 2
wait 500
type "effects"
wait 500
key enter
wait 900

# The row previews its own panel, where everything under the subject is a
# selectable run.
click "copy the demo line"
wait 900
shot s1-job

# The sentence the effect describes itself with.
selectall "job effect"
wait 600
shot s2-effect-selected

# The facts under it — what ran, when, and whether anything out there is
# different for it.
selectall "job facts"
wait 600
shot s3-facts-selected

# A drag across the same run: found, dragged, and nothing broken.
drag "job facts" 240 0
wait 600
shot s4-dragged

# The panel is alive afterwards: the log beside it still answers.
click "copy the demo line"
wait 700
shot s5-alive
quit
