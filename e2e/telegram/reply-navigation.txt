wait 900

key esc

key end

# Only the reply under the cursor offers original. Replying at the other
# end proves that the jump selected the message the quote names.

# well as select: the reply's row resolves only when it is drawn again.

wait 400

wait 400
visible "me: yes — the trailhead car park"
accel "original" o
accel "copy" c
accel "about" a

# composer; cmd+b still returns to the reply and keeps the draft intact.
