# What a letter carries, both ways: the parts of a mail as links
# and a card, and a file from the browser becoming a part of a draft.
#
# Run with `--demo-disk`: the compose half needs a files panel walking the
# demo tree rather than whatever this machine's ~ holds. Assertions are the
# clicks — a label that does not resolve fails the run — so "the letter
# lists its part" is checked by clicking the part, and "the compose carries
# it" by clicking the file the CARRIES line names.
wait 900

# -- reading: the seeded letter that carries a spreadsheet -------------------

# The inbox opens on the demo world; the first thread is Vera's budget
# draft, and the seed gave that letter a real multipart raw.
key cmd 2
wait 400
type "Q3 infra budget"
wait 500
key enter
wait 900
shot a1-thread

# The open message lists its part under the reading: name and size, as a
# link. Clicking it opens the card, joined to the right.
click "q3-budget.csv"
wait 900
shot a2-card

# The card is the file browser's card over the letter's own bytes: the
# kind and size line, the media type where a path would be, and — the part
# being text — the preview under the rule. The line under the name carries
# its own text as its label (a disk card's is the path, a part's is this),
# so clicking it is an assertion about which card this is.
click "preview"
wait 400
click "text/csv"
wait 400
shot a3-preview

# `open` writes the part out to the app's scratch directory and hands it to
# the OS. The fake outside records both, so this proves the verb answers.
click "open"
wait 600
shot a4-opened

# -- writing: a file from the browser becomes a part of a draft -------------

# A blank compose from the launcher. With empty hands it wears send and
# discard, and nothing else — no `attach`, which is the assertion the
# failing click would make.
key cmd 2
wait 400
type "new mail"
wait 500
key enter
wait 900
click "send"
wait 400
shot a5-compose

# A files panel in a column of its own (cmd+enter is always un-joined), and
# a walk to the file: clicking a row previews its card beside the list, and
# *that* card is what wears the object verbs.
key cmd 2
wait 400
type "files"
wait 500
key cmd+enter
wait 900
# The cursor first, then the row: a click previews what the walk is on, so
# the walk is what `enter` goes by.
key down 3
wait 500
click "Downloads/"
wait 500
key enter
wait 800
key down 5
wait 500
click "report-q3.pdf"
wait 700
shot a6-picked
click "copy"
wait 600

# Back to the compose — through the launcher, which focuses a panel that is
# already open rather than opening a second one. It now wears `attach`: the
# hold's other destination, the way a files panel wears `copy here`.
key cmd 2
wait 400
type "new mail"
wait 500
key enter
wait 700
shot a7-attach-offered
click "attach"
wait 800

# The CARRIES line names the file. An attach is an action, so cmd+z takes
# it straight back off — and the click that then fails is the assertion
# that the line went with it.
shot a8-carrying
key cmd+z
wait 800
shot a9-undone

# cmd+shift+z puts it back, and the name is a link to the file's own card
# — addressed in full, since the row it was picked from is still on screen
# one column over.
key cmd+shift+z
wait 800
shot a10-carrying-again
click "report-q3.pdf · 1.2 MB"
wait 800
shot a11-carried-card
quit
