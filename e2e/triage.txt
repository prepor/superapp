# CR-005 — walk, read, triage, next.
#
# Assertions here are the clicks and swipes: a label that does not resolve is
# a failure, so "the preview opened on the right mail" and "that row is gone"
# are checked by the run rather than by a human squinting at a screenshot.
wait 900

# The cursor walk previews. One press down lands on the newest mail and opens
# it joined — WITHOUT taking focus, so the next press keeps walking the list
# rather than scrolling a message body.
click "inbox"
wait 300
key down
wait 500
shot t1-preview-first

# Still the inbox's keyboard: two more steps walk to "Re: superapp panel
# model" (id 3) and the preview follows. If focus had escaped into the
# message, these arrows would have scrolled its body instead and the mail
# below would never resolve.
key down 2
wait 500
shot t2-preview-walked

# The message's own chords, borrowed by the list it is previewed from: cmd+r
# replies from the inbox. `discard` only resolves if the compose really opened.
key cmd+r
wait 700
shot t3-reply-from-inbox
click "discard"
wait 600

# cmd+a archives the previewed mail from the inbox. The cursor carries on to
# the next one and previews it, so the walk survives its own row leaving.
key cmd+a
wait 700
shot t4-archived-from-inbox

# cmd+d deletes the one it landed on — the delete button's chord, lent the
# same way. Both are one action: a single cmd+z takes back the filing *and*
# the cursor move.
key cmd+d
wait 700
shot t5-deleted-from-inbox
key cmd+z
wait 700
shot t6-undone

# Touch triage, through the same state machine android drives. A whole swipe
# runs inside one tick and so never draws — `hold` keeps the finger down so
# the curtain can be photographed mid-wipe.
#
# Short of the commit threshold: a grey wash carrying the word in ink and a
# hairline leading edge, and on release it wipes back out leaving the mail
# alone — "dentist" is still there.
#
# Deliberately swiped on the row the cursor is standing on: an un-armed
# curtain is the same grey as the selection wash, so this is the case where
# only the leading edge distinguishes it.
click "inbox"
wait 400
key down
wait 500
swipe "invite: dentist" -120 0 hold
wait 400
shot t7-curtain-short
drop
wait 700
shot t8-swipe-cancelled
click "invite: dentist"
wait 700

# Past the threshold, left: the curtain inverts to ink and says ARCHIVE,
# entering from the right — the same edge the message header draws it on.
swipe "airport book" -260 0 hold
wait 400
shot t9-curtain-archive
drop
wait 900
shot t10-swiped-archive

# Past the threshold, right: DELETE, entering from the left.
swipe "invoice" 260 0 hold
wait 400
shot t11-curtain-delete
drop
wait 900
shot t12-swiped-delete

# The list is alive afterwards: a row that was never touched still opens.
click "weekly: 14 unread"
wait 700
shot t13-inbox-after

# The guard on borrowed keys (CR-005's fifth rule). Narrow to one mail and
# preview it, then hand the keyboard back to the filter and press cmd+a:
# with a field listening that is select-all, NOT archive. If the guard were
# missing, "Q3 infra" would be filed away and the click below would fail.
#
# Focus is already on the list — clicking a row previews rather than going —
# but say so explicitly: `/` only reaches a filter whose panel has the
# keyboard, and this must not depend on what the step before it left behind.
click "inbox"
wait 400
key /
wait 300
type "vera"
wait 400
key enter
wait 600
key /
wait 300
key cmd+a
wait 500
key esc
wait 400
click "Q3 infra"
wait 700
shot t14-guard-holds
quit
