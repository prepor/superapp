# The height wish. A panel asks the layout for grid units rather than being
# handed a rectangle, and the request is a floor, not a constant: a panel
# whose content needs more rows asks for more, and the same panel goes back to
# the floor when it shows something short again.
#
# The wish belongs to what is shown, not to the slot: it is read off the
# instance after every settle, so the one reader panel changes height as the
# cursor walks. Mail's reader is the panel in this build whose content varies
# enough to see it; the shape of the assertion is the shell's.
