# args:
# env:
#
# Walk, read, file, next — and the batch that does the same to a marked set.
#
# Assertions are the clicks: "the preview opened on the right mail", "that
# row is gone", "the cursor carried on" and "undo put it back" are all
# checked by a label resolving, not by a human reading a screenshot.

wait 900

# -- the cursor walk previews -------------------------------------------------

# A press on a row moves the cursor and previews what it opens, joined —
# without taking focus, so the keys keep walking the list rather than
# scrolling a letter.
click "Q3 infra"
wait 800
shot t1-preview

# Still the list's keyboard: one press down walks to the next conversation
# and the preview follows it. If focus had escaped into the reader, this
# arrow would have scrolled a letter and the mail below would never resolve.
key down
wait 800
shot t2-walked
click "GitHub · aug 31 08:02"
wait 500

# -- filing from the reader's own bar -----------------------------------------

# Archive is the reader's button. It files the conversation, closes every
# panel reading it, and moves the list that was driving it on to the next
# row — one action, so one undo takes all three back.
click "archive"
wait 900
shot t3-archived

# The cursor stood still and the row under it left, so it is now on the one
# below — previewed, which is what this resolving proves.
click "Max Ivanov · aug 31 07:30"
wait 500
shot t4-carried-on

# One step back, because the walk that followed the filing is part of it:
# the press closes what the cursor moved onto *and* gives the conversation
# back — to the inbox, to the panel that was reading it, and to the row the
# list had.
key cmd+z
wait 900
shot t6-undone
click "GitHub · aug 31 08:02"
wait 600

# -- the batch ----------------------------------------------------------------

# Space marks the row under the cursor and the bar grows the verbs over the
# marked set, with their count; shift+down marks the row it leaves and the
# row it lands on.
click "Q3 infra"
wait 700
key space
wait 400
key shift+down
wait 700
shot t7-marked

# Two conversations filed in one action: the marks come off with them, so
# the count goes off the bar. It closes nothing — the cursor stands where it
# stood, which is now the row that took its place, and previews it.
click "archive 2"
wait 900
shot t8-batch
click "Elena Petrova · aug 30 18:20"
wait 500

# One step back, for the reason the reader's *archive* needs one: the walk
# that followed the batch belongs to it. The press brings the mails back
# *and* the marks that filed them — the bar's own `clear` resolving again is
# the proof, since it is up only while something is marked.
key cmd+z
wait 900
shot t9-marks-restored
click "clear"
wait 600
shot t10-cleared

# The list is alive afterwards, with nothing marked and no bar in the way.
click "that airport book"
wait 800

# -- the chords the list borrows ----------------------------------------------

# A chord is offered in one order: the workspace's own, then the focused
# widget, then the focused panel's bar, then the bar of the panel it
# previews. The last step is what lets a list act on the thing under its
# cursor without moving focus.
#
# The list's own bar wears `sync` and nothing else while nothing is marked,
# so `r` and `a` fall through to the reader beside it: cmd+r opens the reply
# its bar carries — `discard` resolving is the proof — and cmd+a files the
# conversation the cursor is on.
click "invite: dentist"
wait 800
key cmd+r
wait 900
shot t11-reply-borrowed
click "discard"
wait 800
key cmd+a
wait 900
shot t12-archived-borrowed

# The cursor stood still and the row under it left, so it is now on the one
# below — previewed, which is what this resolving proves.
click "invoice 2026-08"
wait 700
key cmd+z
wait 900
key cmd+z
wait 900
click "invite: dentist"
wait 800
shot t13-borrowed-undone

# -- and the guard over them --------------------------------------------------

# While a field has the keyboard the chords are its own: cmd+a is select-all
# there, not the archive it would be a keystroke earlier. If the guard were
# missing this would file the conversation away, and the click below — the
# same row, still in the inbox — would fail.
key /
wait 400
type "vera"
wait 500
key enter
wait 700
key /
wait 400
key cmd+a
wait 600
key esc
wait 500
click "Q3 infra"
wait 800
shot t14-guard-holds
quit
