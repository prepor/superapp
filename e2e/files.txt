# CR-008 — the file browser writes. `new dir`, `copy here`, `move here`
# and `delete` reach the disk through the outside, and every one of them
# is an undoable action whose reversal is another one: a delete is a move
# to the trash, and undo is the move back.
#
# Run with `--demo-disk`, so the tree is the fixture rather than whatever
# this machine's ~ holds. The assertion is the click: a row that resolves
# is a path that is there. Where two panels could be showing a row of the
# same name, the card's own path line settles which — it resolves only
# for the file the card is actually on.
wait 900

# The launcher opens the files root; ~ lists the demo tree.
key cmd 2
wait 400
type "files"
wait 400
key enter
wait 900

# -- new dir ------------------------------------------------------------
# The field above the rows makes one directory, and the row it made is
# the proof.
click "new dir"
wait 500
type "reports"
wait 500
key enter
wait 800
shot w1-made

# The click opens a preview on it, and a preview that drives nothing is
# the object: `delete` acts on the new directory.
click "reports/"
wait 800
click "delete"
wait 800
shot w2-deleted

# …to the trash, never `rm` — and `go to` reaches that like any other
# directory. (The field is seeded with where the panel stands; a second
# root inside the text restarts the path.)
click "go to"
wait 400
type "~/.Trash/"
wait 600
key enter
wait 900
click "reports/"
wait 800
shot w3-in-the-trash

# ⌘z takes back the preview that click opened; `go to` carries the one
# panel left to where the rest of this walk happens.
key cmd+z
wait 700
click "go to"
wait 400
type "~/Downloads/"
wait 600
key enter
wait 900

# -- copy ---------------------------------------------------------------
# The card under the cursor is the object: `copy` holds the file it
# shows, and every files panel then offers `copy here`. Into the
# directory the file is already in is the one clash a copy is allowed —
# the duplicate is the point — so it lands under a name that is free.
click "README.txt"
wait 800
click "copy"
wait 500
click "copy here"
wait 900
shot w4-copied
click "README copy.txt"
wait 800
click "~/Downloads/README copy.txt"
wait 600

# ⌘z takes back the preview that click opened, and the one under it takes
# back the copy — into the trash, like everything else this app removes.
key cmd+z
wait 700
key cmd+z
wait 900

# -- move ---------------------------------------------------------------
# The same file, moved. The card holds it; `go to` then carries the one
# files panel into the directory it is to land in, and `move here` is
# that panel's — the hold is a set of paths, not a place, so walking the
# destination to it is the whole gesture.
click "README.txt"
wait 800
click "move"
wait 500
click "go to"
wait 400
type "~/Downloads/2026/"
wait 600
key enter
wait 900
click "move here"
wait 900
shot w5-moved
click "README.txt"
wait 800
click "~/Downloads/2026/README.txt"
wait 600

# -- delete -------------------------------------------------------------
# The card is the object again: `delete` takes the file away and closes
# the panel that was showing it. ⌘z brings both back — the file to where
# the move left it, and the card onto it.
click "delete"
wait 800
key cmd+z
wait 900
shot w6-restored
click "README.txt"
wait 800
click "~/Downloads/2026/README.txt"
wait 600
quit
